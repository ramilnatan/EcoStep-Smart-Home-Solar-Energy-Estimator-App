# EcoStep - Smart Home Solar & Energy Estimator

Calculate your solar savings, battery backup, and energy independence with EcoStep's intelligent home energy estimator. Get a custom system blueprint and ROI report.

## Features

- Smart home appliance energy consumption calculator
- Solar system sizing and ROI analysis
- Battery backup runtime calculations
- Grid independence metrics
- Real-time energy savings estimates
- Multi-currency support
- Lead capture and management

## Tech Stack

- React with TypeScript
- Vite for fast development
- Tailwind CSS for styling
- Supabase for backend
- Lucide React for icons

## Getting Started

1. Clone the repository
2. Install dependencies: `npm install`
3. Set up environment variables in `.env.local` (use `.env.example` as reference)
4. Start development server: `npm run dev`
5. Build for production: `npm run build`

## Environment Variables

- `VITE_SUPABASE_URL` - Your Supabase project URL
- `VITE_SUPABASE_ANON_KEY` - Your Supabase anon key

See `.env.example` for details.
